# CodeAlpha Frontend Development Projects

Welcome to my Frontend Development Projects repository! 👋

This repository contains two frontend projects developed using HTML, CSS, and JavaScript as part of my CodeAlpha internship tasks.

## 🚀 Projects

### 1. Calculator 🧮

A simple and interactive calculator built using HTML, CSS, and JavaScript.

**Features:**
- Basic arithmetic operations.
- Addition, subtraction, multiplication, and division.
- User-friendly interface.
- Responsive design.
- Interactive buttons.

**Technologies Used:**
- HTML5
- CSS3
- JavaScript

**Project Files:**
- `index.html` – Structure of the calculator.
- `style.css` – Styling and layout.
- `script.js` – Calculator functionality.

### 2. Image Gallery 🖼️

A responsive image gallery built using HTML, CSS, and JavaScript.

**Features:**
- Displays images in a gallery layout.
- Next and Previous navigation buttons.
- Lightbox view for viewing images.
- Hover effects and smooth transitions.
- Responsive design for different screen sizes.

**Technologies Used:**
- HTML5
- CSS3
- JavaScript

**Project Files:**
- `index.html` – Structure of the image gallery.
- `style.css` – Gallery styling and layout.
- `script.js` – Navigation and interactive functionality.
